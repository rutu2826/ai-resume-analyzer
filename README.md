# 🤖 AI Resume Analyzer

A beginner-friendly Streamlit project that analyzes a resume PDF against selected internship roles.

## Features
- PDF resume upload
- Resume text extraction
- Target-role selection
- Relevant skill detection
- Match score
- Missing/recommended skills
- Resume improvement suggestions

## Tech Stack
Python, Streamlit, pdfplumber, regular expressions

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

This version uses local text processing and rule-based matching, so no API key is required.
